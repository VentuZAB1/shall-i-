# 3 new thumbnails for ChatGPT (2026-10-29)

Style to copy: `00_STYLE_best_thumbnail.png`, the slingshot and pixel egg, our best thumbnail by engagement.
New ideas, all different from the 10-22 set (launch / 1% secret / tsunami run):
1. **Ice Dragon:** the Glacier update (news hook).
2. **Pet Army:** collect pets, get rich (collection hook).
3. **BONK!:** knock other players' eggs away (social chaos hook).

## How to use
- Start a **new chat** for each thumbnail. Upload the images listed for it FIRST, then paste the prompt.
- If the result is close but not right, send ONE fix at a time (see "Fix lines" at the bottom).
- Text: leave it out of the image. AI text often comes out misspelled. Add 1-3 words afterwards if you want (Claude can
  do it with the same font as the 10-22 set).
- Size: Roblox wants 1920x1080 (16:9). ChatGPT makes 1536x1024, so crop the top and bottom a little. The prompts keep
  everything important in the middle, so the crop is safe.
- Test before uploading: shrink it to the size of a phone game tile (~250 px wide). You should still see what's going on
  in one second.
