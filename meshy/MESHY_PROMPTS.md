Kept from Claude Design (no prompt needed): Forest Stag (Fawn), Vine Serpent, Treant, Mossback Tortoise, so the GRASS area is done.
Every prompt already includes the 3 rules (scary, big, not Roblox-y). The Fire, Shadow and Celestial names are Claude's proposals, so swap any you don't like.

## Meshy settings (use for every creature)

**Preview (Text to 3D · Preview):**
- Model Type: **Standard**
- AI Model: **Latest** (that's Meshy 7.1)
- Geometry Resolution: **Standard** (2K/4K cost more, and the extra detail gets lost when we cut it down for Roblox)
- Enable Moderation: **off**
- Should Remesh: **on** (cleaner mesh; if a polycount box appears, set it to **10000**)
- Pose: **None** (A-pose/T-pose are for humanoids)
- Auto Size: **off** (we scale in Studio)
- Target Formats: **glb** + **fbx**
- Alpha Thumbnail: **on** (a transparent-background picture we can use as the pet icon in the UI)

**If a preview looks good, Refine (Text to 3D · Refine) it:** PBR **on**, texture resolution **2K**, Remove Lighting **on**, formats **glb** + **fbx**.

**Smart Topology:** only use it as a fallback, if Standard comes out too heavy or messy. Set Target Polycount to **8000**, keep the rest the same.

Save each download into `SLINGSHOT Creatures\meshy\<Name>\`.
